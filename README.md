# Linyan

Local storyboard-to-video app.

## Layout

- `app.py` Flask app
- `templates/` UI template
- `requirements.txt` Python deps
- `data/` local DB, uploads, outputs
- `assets/` sample storyboard, voiceover, and render artifacts

## Run

```bash
cd /Users/mengweetan/.openclaw/workspace-anthony/linyan
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```
